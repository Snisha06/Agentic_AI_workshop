# 📦 Logistics Optimization Analysis with CrewAI

A CrewAI-powered system that analyzes logistics operations for a given product list and produces optimized strategies using a two-agent, sequential workflow.

---

## 🧠 Agents

1. **Logistics Analyst Agent**

   - Role: Investigates current operations (route efficiency, stocking, bottlenecks)
   - Input: List of products

2. **Optimization Strategist Agent**
   - Role: Designs data-driven optimization plans (route tweaks, inventory policies)
   - Input: Insights + product list
