# 🧳 Travel Assistant AI

An intelligent Travel Assistant that:

1. Fetches **current weather** for your destination.
2. Retrieves **top local attractions**.
3. Delivers well-structured responses via a language model.

---

## ✅ Setup

```bash

cd travel_assistant_ai
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Add your API keys in a .env file:

OPENAI_API_KEY=your_openai_key
WEATHER_API_KEY=your_weatherapi_key

Run
python main.py
