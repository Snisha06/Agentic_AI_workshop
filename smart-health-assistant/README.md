# 🤖 Smart Health Assistant

A multi-step conversational assistant that personalizes BMI evaluation, diet planning, and workout scheduling.

## 🧠 Agents & Flow

1. **User Proxy Agent** – collects user input.
2. **BMI Tool** – calculates BMI.
3. **BMI Agent** – evaluates BMI and gives health recommendations.
4. **Diet Planner Agent** – creates a meal plan based on BMI and preferences.
5. **Workout Scheduler Agent** – schedules weekly workouts based on demographic info.
