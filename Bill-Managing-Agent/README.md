# Bill Managing Agent

**A group-chat style AI assistant to process bill images, categorize expenses, and highlight spending patterns.**

## 🧠 Objective

This project simulates a group of three cooperative agents:

1. **User Proxy Agent** – initiates by uploading the bill image.
2. **Bill Processing Agent** – processes the image, extracts text, and categories expenses.
3. **Expense Summarization Agent** – analyzes spend data and produces insights.

## ⚙️ Setup Instructions

```bash
git clone https://github.com/YOUR_USERNAME/bill-managing-agent.git
cd bill-managing-agent
python3 -m venv venv
source venv/bin/activate     # Windows: venv\Scripts\activate
pip install -r requirements.txt
```
