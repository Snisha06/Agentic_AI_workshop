# Streamlined EDA System with Autogen Agents

This project automates Exploratory Data Analysis (EDA) using a multi-agent system built with Autogen.

## 🧠 Agents Overview

- **Data Preparation Agent**: Cleans the data
- **EDA Agent**: Generates stats & plots
- **Report Generator Agent**: Builds a Markdown report
- **Critic Agent**: Reviews report clarity & structure
- **Executor Agent**: Validates data & results
- **Admin Agent**: Orchestrates the workflow

## ⚙️ Setup & Run

```bash

cd eda_autogen_system
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt



```
